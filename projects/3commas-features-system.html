3Commas Features System

  • Crypto
  • Trading Tools

A scalable feature system for 3Commas, designed to simplify complex trading workflows and create consistent UI patterns across data-heavy product areas.

Type
Web
Role
Year
Team

Context

3Commas is a platform for automated crypto trading, founded in 2017. Traders connect accounts on more than 15 exchanges, including Binance, Bybit, OKX and Coinbase, and manage bots and orders across all of them from one place.

Its core tools are trading bots and SmartTrade: the DCA bot builds a position for a better average entry price, the Grid bot works sideways markets, the Signal bot trades on TradingView alerts, and SmartTrade is a manual trading terminal with take profit and trailing stop loss built in.

Each of these tools grew its own screens, settings and tables. The feature system gives them one set of building blocks and UI patterns, so complex, data-heavy areas look and behave the same and new features ship without inventing a new interface.
