# Melix — портфолио Владимира Мелихетяна

Статичный сайт (HTML + CSS + JS), без сборки и зависимостей. Перенесён с melix.framer.website.

## Структура

```
index.html            главная
works.html            все работы (Web, Applications, Brand Identity)
about.html            обо мне
404.html
projects/<slug>.html  страница каждого проекта (32 шт.)
assets/css/style.css  все стили
assets/js/main.js     видео в карточках, слайдер, режим черновика
assets/cases/<slug>/  сюда класть картинки и комиксы для кейса
scripts/download-assets.mjs  скачать медиа с Framer к себе
vercel.json           чистые адреса: /works, /about, /projects/u7buy
```

## Залить на Vercel

**Через GitHub (удобнее всего):**
1. Создай репозиторий и загрузи туда содержимое этой папки.
2. На vercel.com: Add New → Project → выбери репозиторий.
3. Framework Preset: **Other**. Build Command и Output Directory оставь пустыми.
4. Deploy.

**Без GitHub:** `npm i -g vercel`, затем в папке проекта `vercel` и после проверки `vercel --prod`.

## Важно: перенеси медиа с Framer к себе

Сейчас картинки и видео грузятся с CDN Framer (framerusercontent.com). Если удалишь проект во Framer, они могут пропасть. Чтобы сохранить всё у себя, один раз запусти (нужен Node 18+):

```
node scripts/download-assets.mjs
```

Скрипт скачает ~60 файлов в `assets/media/` и сам поменяет ссылки в HTML. Видео весят прилично, загрузка займёт пару минут. Потом закоммить и задеплой.

## Как заполнить кейс проекта

Открой `projects/<slug>.html` (например `projects/u7buy.html`). Вверху файла есть комментарий с инструкцией.

1. **Картинки / комиксы.** Положи файлы в `assets/cases/<slug>/` с именами `01.jpg`, `02.jpg` и т.д. В блоке `<section class="gallery">` каждая строка `<figure>` — одна картинка. Нужно больше — скопируй строку и поменяй номер. Другой формат (png, webp, gif) — поменяй расширение в `src`. Подпись пиши внутрь `<figcaption>`.
2. **Тексты.** Блоки Context / Problem / Process / Result и поля Role / Year / Team. Пиши текст прямо внутрь тега с `data-slot`, например:
   ```html
   <div data-slot="..."><p>Первый абзац.</p><p>Второй абзац.</p></div>
   ```

**Пустые блоки и несуществующие картинки на сайте не показываются**, так что можно заполнять кейсы постепенно.

**Режим черновика:** открой страницу локально или добавь к адресу `?draft` (например `https://твой-домен/projects/u7buy?draft`) — пустые места подсветятся пунктиром с подсказками, что и куда класть.

## Посмотреть локально

```
npx serve .
```
и открыть http://localhost:3000 (адреса без .html работают так же, как на Vercel).

## Править контент на главной / в списке работ

Тексты карточек, компании, Figma-ссылки, контакты лежат прямо в `index.html`, `works.html`, `about.html`. Шапка и подвал повторяются в каждом файле: если меняешь почту или ссылки, используй поиск с заменой по всем файлам.
